# 코인원 거래량 증가 분석 (2026-11-04)

코인원의 국내 점유율(24시간 원화 거래대금 약 16~17%)이 왜 높아졌는지, 특히 BTC와 USDC 거래가 어떻게 만들어지는지를 공개 데이터로 분석했습니다.

## 결론 요약

- 증가분은 수수료 0%(8/21 API, 8/26 앱·웹 바우처)와 거래량 순위 상금(랭킹전, 5종목: BTC·ETH·XRP·DOGE·USDC)에 반응한 소수 자동거래 계정이 만든 반복 거래가 대부분입니다. 대상 5종목만 점유율이 5~18배 올랐습니다.
- BTC: 바이낸스 가격을 1초 안에 따라가는 시장조성 봇이 호가를 채우고, 거래는 소수 계정에 쏠려 있습니다(11/3 BTC 상위 3명 53%).
- USDC: 국내 원화 USDC 거래의 96%가 코인원에 있고, 하루 거래의 68%가 몇 분짜리 대량 체결이었습니다. 체결량이 지갑 입출금의 약 70배여서 새 자금보다 거래소 안 재고의 반복 거래로 보입니다.
- 원화가 해외로 빠져나가는 흐름의 증거는 찾지 못했습니다. 온체인 흐름은 여러 해외 거래소와 양방향입니다.
- 보상이 끝나면 대상 종목 거래가 90% 넘게 줄어든 전례가 있어, 랭킹전3 종료(11/15) 이후가 판별 시점입니다.
